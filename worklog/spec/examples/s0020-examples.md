# Examples

## Implementation status

The Fastify web server example (s0021) is implemented under `examples/fastify-web-server`.
The stock-market example in s0022 remains deferred.

## Behavior

- Example projects live under `examples/`.
- Implemented examples demonstrate typed component calls, component state, gateway integration, logging, and validated configuration through natural use.

## Constraints

- Examples MUST NOT contain credentials, tokens, or environment-specific assumptions.
- Non-working API sketches MUST NOT be presented as runnable or imply unsupported behavior.

## Anticipated changes

- Additional examples may be added under their own specs.
