## Behavior

- Example projects live under `examples/`.
- Implemented examples demonstrate typed component calls, component state,
  gateway integration, logging, and validated configuration through natural
  use.

## Constraints

- Examples MUST NOT contain credentials, tokens, or environment-specific
  assumptions.
- Non-working API sketches MUST NOT be presented as runnable or imply
  unsupported behavior.

## Anticipated Changes

- Additional examples may be added under their own specs.
